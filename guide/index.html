GAON# 앱 설치 방법

순서대로 따라 하면 3분이면 끝나요.
설치하면 공지·승인 알림이 폰으로 와요.

✅ 이미 앱으로 열려 있어요!
설치가 끝난 상태예요. 이 창은 닫아도 돼요.
⚠️ 지금 카카오톡 안에서 열려 있어요.
여기서는 설치가 안 돼요. 아래 버튼을 눌러 사파리크롬로 다시 열어 주세요. 사파리로 열기
1

사파리에서 GAON# 열기

아래 검은 버튼을 눌러요.
꼭 사파리(Safari)에서 열려야 해요.

GAON# 열기

크롬·카카오톡·네이버 앱 안에서 열리면 안 돼요.

2

공유 버튼 누르기

화면 맨 아래(또는 위)에 있는 공유 버튼을 눌러요.

← 이렇게 생긴 버튼

공유 버튼이 안 보이면 오른쪽 아래 ··· 를 먼저 누르고, 거기서 공유를 눌러요.

3

"홈 화면에 추가" 누르기

올라온 메뉴를 아래로 내리면 있어요.

복사 ⧉
즐겨찾기에 추가 ☆
홈 화면에 추가 ⊞
4

오른쪽 위 "추가" 누르기

이름이 GAON# 으로 되어 있으면 그대로 추가를 눌러요.

"웹 앱으로 열기"가 보이면 켜진 상태(초록색)로 둬요.

5

사파리는 닫고, 홈 화면의 GAON# 아이콘 누르기

← 홈 화면에 생긴 아이콘

앞으로는 항상 이 아이콘으로 들어가요.
사파리로 들어가면 알림이 오지 않아요.

6

로그인 → "알림 켜기" → "허용"

내 코드를 넣고 로그인하면 알림 안내창이 떠요.
알림 켜기 누르고, 나오는 창에서 허용을 눌러요.

안내창이 안 뜨면: 왼쪽 위 메뉴 → 설정 → 알림 켜기

1

크롬에서 GAON# 열기

아래 검은 버튼을 눌러요.
꼭 크롬(Chrome)에서 열려야 해요.

GAON# 열기

삼성 인터넷·카카오톡·네이버 앱 안에서 열리면 안 돼요.

2

오른쪽 위 점 3개 ⋮ 누르기

← 주소창 오른쪽에 있어요

화면 아래에 "앱 설치" 안내가 바로 뜨면 그걸 눌러도 돼요. (3번으로)

3

"앱 설치" 누르기

새 탭 ＋
방문 기록 ↺
앱 설치 ⤓

"앱 설치"가 없으면 "홈 화면에 추가" → "설치"를 눌러요.

4

"설치" 누르기

작은 창이 뜨면 설치를 눌러요.
잠시 후 홈 화면에 아이콘이 생겨요.

5

크롬은 닫고, 홈 화면의 GAON# 아이콘 누르기

← 홈 화면에 생긴 아이콘

앞으로는 항상 이 아이콘으로 들어가요.

6

로그인 → "알림 켜기" → "허용"

내 코드를 넣고 로그인하면 알림 안내창이 떠요.
알림 켜기 누르고, 나오는 창에서 허용을 눌러요.

안내창이 안 뜨면: 왼쪽 위 메뉴 → 설정 → 알림 켜기

7

(삼성폰) 알림이 화면에 뜨게 하기

폰 설정 → 애플리케이션 → GAON# → 알림에서
잠금화면, 팝업을 켜 주세요.

소리만 나고 화면에 안 보일 때 이걸 하면 돼요.

🎉 끝! 홈 화면의 GAON# 아이콘으로 들어가고,
알림이 오면 눌러서 바로 확인하면 돼요.

잘 안 될 때

"허용"을 안 누르고 닫아버렸어요

아이폰: 폰 설정 → 알림 → GAON# → 알림 허용 켜기.

안드로이드: 폰 설정 → 애플리케이션 → GAON# → 알림 → 켜기.
(GAON#이 목록에 없으면 Chrome → 알림 → 사이트에서 ksh015.github.io 허용)

아이폰에 "홈 화면에 추가"가 없어요

사파리가 아닌 다른 앱에서 열린 거예요. 위의 GAON# 열기 버튼을 길게 눌러 링크를 복사한 뒤, 사파리 주소창에 붙여넣어 열어 주세요.

알림이 안 와요

① 사파리/크롬이 아니라 홈 화면 아이콘으로 들어갔는지 확인해요.
② 앱 → 메뉴 → 설정 → 알림 켜기를 한 번 더 눌러요.
③ 아이폰은 iOS 16.4 이상이어야 해요. (설정 → 일반 → 소프트웨어 업데이트)
④ 폰이 방해금지/집중 모드면 알림이 안 울려요.

로그인할 때마다 코드를 넣어야 해요

로그인 화면에서 코드 저장에 체크한 뒤 로그인하면 다음부터는 코드가 채워져 있어요.

예전에 쓰던 GAON 아이콘은요?

안내가 있을 때까지는 둘 다 써도 돼요. 같은 내용이 보여요. 알림은 새로 설치한 앱에서만 와요.
